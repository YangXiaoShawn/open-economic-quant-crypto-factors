# 开源微观结构因子的加密货币迁移 — 研究报告

> ⚠ **本文定稿于 2026-06-19, 数据止于 2026-05-31。后续复核:
> [`UPDATE_2026-07.md`](UPDATE_2026-07.md) (至 07-28)、[`UPDATE_2026-08.md`](UPDATE_2026-08.md)
> (至 08-15, YTD/七月初/近15天)。请以最新 UPDATE 为准。**

> 一句话结论: **把"开源证券·市场微观结构系列"的因子搬到 crypto, 验证了"数据墙消失"——
> A 股卡死的分钟/逐笔/订单簿/资金流数据在交易所 API 免费即得; 经 730 天回测 + 多维样本外
> 检验, 真正可迁移的王牌是永续 `funding 资金费率` (A 股完全没有的维度), 但 alpha 必须做成
> 市场中性(现货多头 + perp 指数空头)才拿得到, 裸多头会被 crypto 的 beta 吃掉。**

---

## 1. 背景与命题
开源证券金工"市场微观结构研究系列"(1–32 篇)在 A 股的复现, 长期卡在**数据可得性**: 分钟线、
逐笔成交方向、Level-2 盘口、撤单等都需付费且受限。本项目的命题: **同一套因子逻辑搬到数字货币,
数据墙是否消失?** 结论是肯定的, 且 crypto 额外提供 A 股没有的**永续衍生品资金流维度**(funding /
持仓量 OI / 多空比)。

## 2. 数据与方法
| 项 | 内容 |
|---|---|
| 交易所连通性 | 本环境 Binance/Bybit/KuCoin API 被 geo-block; **仅 OKX 可 ccxt 直连**。但 `data.binance.vision` 免费 dump (与被封 api 不同 host) 可达。 |
| 主数据 | Binance 现货+永续 1m dump (含 `taker_buy_quote`=真逐笔方向聚合) + 月度 funding + 日档 OI/多空比, **105 币 × 730 天 (2024-06~2026-05)**。 |
| 样本外数据 | OKX 日线 OHLCV + funding 历史 (ccxt 直连), 用于跨交易所验证。 |
| 回测口径 | 横截面五分位多空, 日调仓, 单边 5bps; 大币池每腿~5 名。年化按 365 天。 |
| 工具 | python / pandas / scipy(SLSQP 约束优化) / ccxt / matplotlib。 |

## 3. 研究主线与关键发现 (每一步都被数据推翻过假设)

**① 样本长度直接改写结论。** 120 天窗口的"大赢家"(量波同步夏普 +3.50、APM +1.93)在 730 天上
**全部翻负**; 而 120 天像噪声的理想反转 (−0.59) 在 730 天变全场最佳。→ **短样本会系统性造出
假因子**, 数百天才稳。

**② 每个因子有各自最优"币池广度"。** 把池子从 24→60→105 币:
- 价格反转/动量在中池(~60)见顶, 加入垃圾 perp 反伤;
- 低价位振幅随广度**单调走强**;
- **taker 主动买卖资金流跨池极不稳 (0.73/0.10/1.62) → 必须钉死大币池**;
- **funding 各池皆强 (1.42/2.83/2.52) → 唯一可泛化的资金流信号。**

**③ funding/OI 是 A 股没有的新维度, 且与价量正交。** 资金费率夏普 1.42、散户多空比 1.39,
与价量/T2 资金流相关都 <30%。"跟大户多空比"反而亏 (−1.36) → 币安 top-trader 不是聪明钱, 该 fade。

**④ 约束优化的价值在"剔除"而非"精配"。** scipy 做 max_sharpe/min_var/risk_parity (walk-forward
防前视): 因子全好时**等权 1/N 打赢 MVO**(估计误差, DeMiguel 现象); 混入坏因子时**约束 max_sharpe
靠把坏因子压到 0 权反超等权**(夏普 0.39→0.89)。

**⑤ 回测去水分: 多数 alpha 活在空腿。** 现货不能做空, 空腿走 perp 要计提资金费。三口径检验:
funding 计提**不毁因子**(对情绪类还加分, 因空腿压在高 funding 拥挤多头上是**收**费); 但**纯现货
多头**下理想反转/大单资金流报废, 只有**低价位振幅/资金费率/散户多空比**仍正超额。funding 收益
**83% 是真价格反转, 17% 是 carry** → 是真预测 alpha, 不是单纯薅费。

**⑥ 深挖 funding: 简单最优。** 条件双重排序(funding×超买)夏普 1.29 < 纯单排序 1.73; 时序择时
仅极端档有效、中段噪声。→ 已验证的强简单因子, 加花哨多半变差。

## 4. 因子可迁移性总表 (经全部检验后的最终判定)

| 因子 | 类型 | 730天夏普 | 样本外检验 | 判定 |
|---|---|---|---|---|
| **资金费率 funding** | 永续★ | +1.42 | 两半皆正·参数稳·滚动91%正·**OKX跨所+5.16同号** | 🏆 王牌 |
| 散户多空比 | 永续★ | +1.39 | 两半皆正·参数稳 | ✅ 稳健 |
| 低价位振幅 | 价格 | +1.63 | 两半皆正·参数最稳·OKX同号 | ✅ 稳健(偏熊市防御) |
| 大额主动买 | T2资金流 | +0.73 | 两半皆正但**参数脆弱** | ◐ 低置信 |
| 理想反转 | 价格 | +0.25 | 两半皆正但**参数脆弱** | ◐ 低置信 |
| 截面动量 | 价格 | −0.38 | 两半皆负 | ✗ 不迁移 |
| 聪明钱Q/APM/量波同步/单笔金额… | 价格 | <0 | — | ✗ 不迁移 |

**A 股 vs crypto 反差**: A 股所有反转类因子都有效; crypto **只有"高换手分钟反转"这一支迁移**,
其余反转味全失效 → crypto 日内更"趋势"。真正稳的是 **funding / 振幅 / 散户拥挤** 这三个。

## 5. 可交付策略 (`deploy_spot.py`)
把三个**样本外最稳**的因子(低价位振幅 + 资金费率 + 散户多空比, 恰好就是参数最不敏感的三个)
合成横截面 z-score 复合分, 大币池取 top8 等权:

| 形态 | 净值 | 夏普 | 回撤 | 周换手 |
|---|---|---|---|---|
| 纯现货多头 (top8·周调) | 0.59 | −0.54 | −56% | 5% |
| **多头 + perp 空指数对冲 beta (纯 alpha)** | **1.35** | **+1.18** | **−11%** | 5% |

- **纯现货多头逃不过熊市 beta** (本窗 alt 大熊, 基准 −50~−76%), 虽显著跑赢基准但绝对仍亏;
- **市场中性形态 = 现货多头篮子 + perp 空一个指数** → 纯 alpha 夏普 1.18、回撤仅 −11%、
  周换手 5%, 对 5–30bps 成本不敏感;
- 工程: 周/双周调仓是甜点; top8 平衡收益与分散。

## 6. 实时检测前端 (`live_monitor.py` + `dashboard.html`)
把王牌信号接到 OKX 实时行情的浏览器看板 (仅标准库, 无需 Flask):
- **实时组合净值**: 市场中性策略(现货多头 − perp 指数空头)的净值曲线 —— 用 OKX 日线缓存回算近 ~95 日
  (funding 历史经 ccxt 仅 3 月) 作历史段, 末点用当前实时行情 mark, 每刷新更新;附今日实时 P&L 与夏普/年化/回撤;
- **下单清单(目标权重)**: 🟢 LONG 现货等权(各 +1/k) + 🛡 对冲腿 perp 指数空头(−100%, 中和 beta) +
  🔴 SHORT perp 横截面替代腿(各 −1/k), 带实时价格 —— 可直接照单下单;
- **全市场拥挤度计**: 平均资金费率(年化)→ risk-on/off (funding_deep 显示极高拥挤=大盘见顶风险);
- **全池因子明细**: 价格、资金费率年化、funding/振幅 z-bar、24h 涨跌、复合分、信号;每 60s 刷新。
> 注: 实时净值的近窗(OKX 95 日)与全样本验证(Binance 510 日, 夏普 1.18)是两个不同口径——看板既给
> "现在的实证净值", 也在脚注标明"全样本验证夏普", 不混淆。

运行: `python live_monitor.py` → 浏览器 `http://127.0.0.1:8765`。预览见 `dashboard_preview.png`。

## 7. 风险与局限 (诚实声明)
- **回测仍有理想化**: 次日收盘成交、无冲击成本、分位内等权、大币池每腿仅~5 名;
- **样本期是 alt 大熊**: 低价位振幅的超高夏普部分是熊市防御属性, 牛市未必复刻;
- **OKX funding 史经 ccxt 仅可回溯 ~3 月**, 跨所验证窗口短(同号但样本小);
- **funding 因子需做空**: 拿满 alpha 必须 perp 空腿, 涉及强平/保证金/资金费实际计提管理;
- 本项目为研究/教育用途, **非投资建议**。
