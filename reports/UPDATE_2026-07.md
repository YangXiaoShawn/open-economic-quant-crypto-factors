## 0. 方法学: 为什么这次的新窗口是"真"样本外

- 这些因子**全是横截面排序**, 没有需要拟合的参数。所以我把**全样本算一遍日收益序列,
  再按日期切片**统计 —— 新窗口的每一天在上次定稿时都还不存在, 没有任何前视。
- **复核过口径一致性**: 把面板截回 2026-05-31 重跑, 复现了上次 README 的夏普 —— 理想反转
  +0.25 / 截面动量 −0.38 / 低价位振幅 +1.63 / 大额主动买 +0.73 / 资金费率 +1.42, **逐个对上**。
  所以"旧窗 vs 新窗"的对比是可信的, 不是换了口径造成的差异。
  (散户多空比 复刻得 +1.28, 上次 README 记的是 +1.39, 是唯一对不上的一个, 差异来源未查明。)
- 新窗口只有 1~2 个月。**年化和夏普是强外推, 噪声极大**; 区间累计收益、日胜率、天数才是硬事实。
  下表一律标天数。

## 3. funding 因子出了什么事 —— 分腿看

把多空拆开, 对比"每条腿相对市场的超额":

| 因子 | 窗口 | 多腿超额 | 空腿超额 | 多空合计 |
|---|---|---|---|---|
| 资金费率 | 旧窗 729天 | +37.7% | **−29.2%** (空对了) | 正 |
| 资金费率 | **新窗 30天** | +4.0% | **+9.5%** (空错了) | **负** |
| 散户多空比 | 新窗 57天 | +9.8% | +0.8% | 正 |
| 低价位振幅 | 新窗 57天 | +0.2% | −8.8% | 正 |

**结论: funding 的多腿(买低/负 funding 币)其实还在赚 (+4.0% 超额), 死的是空腿。**
6 月这种全市场同步崩跌里, "高 funding = 拥挤多头 = 该跌更多"不成立 —— 高 funding 币反而
比市场抗跌 9.5%。这是**拥挤度类因子的典型失效场景**: 它赌的是分化, 而崩跌是齐跌。

顺带: 低价位振幅这次的钱**全部来自空腿** (多腿超额只有 +0.2%), 和旧窗 (多腿 +27.8%) 完全
反过来 —— 也就是它的**纯现货多头版本这两个月是不赚钱的** (见下表 −0.6%)。

## 6. 为什么 funding 只更新到 2026-06-30 (以及不要用 proxy)

`data.binance.vision` 的 **fundingRate 只有 monthly 档, 没有 daily 档** (klines / OI metrics /
premiumIndexKlines 都有 daily)。所以当月未结束时, funding 拿不到。7 月的 funding 得等 8 月初。

我试过用 `premiumIndexKlines` 按币安公式反推 (`update_data.py funding_proxy_days`),
并在 2026-06 上做实测校验 (`update_data.py validate`) —— **结论是不合格, 已弃用**:

| 指标 | 实测 | 判定线 |
|---|---|---|
| 逐点 corr(真实, proxy) | 0.798 | — |
| 横截面秩相关 · 全池 | **0.56** | >0.95 |
| 横截面秩相关 · 大币池24 | **0.91** | >0.95 |

公式本身是对的 (残差恰好等于 clamp 值 5bp, 说明 `F = P + clamp(I−P)` 的结构对上了), 1m 采样
也修过 (用 1h close 采样只有 0.65~0.73 —— 币安取的是**逐分钟**均值)。真正卡住的是:
**interest rate / clamp / cap 是币安逐品种设定的, 无法从公开 dump 反推**, 全池 100 个币
参数各异 → 秩相关只有 0.56。

**所以: 价格类 / OI 类因子更新到 2026-07-28, funding 类止于 2026-06-30, 两者末日不同, 报告里
逐行标注天数。** 这也是为什么上表里 funding 相关的行是 30 天而不是 57 天。

## 7. 结论怎么改

1. **"funding 是王牌"这个结论要降级为"条件成立"。** 它在 730 天上确实最强, 但新窗第一次
   遇到"齐跌"环境就翻负, 且失效点明确在**空腿**。上次 README 说它"滚动91%正" —— 这个
   91% 现在要重算。它不是坏因子, 但它对市场结构 (分化 vs 齐跌) 有依赖, 不该单押。
2. **"散户多空比"应该升级。** 全样本夏普 1.40 已是最高, 新窗 3.03, 且纯多头版本也是新窗
   唯一明显有效的 (+10.9%)。它和 funding 都是拥挤度, 但衡量的是**散户账户数**而非**资金费**,
   两者在新窗分道扬镳 —— 说明它们不是同一个东西。
3. **低价位振幅仍是最稳的价格类因子** (全样本 1.58, 新窗 2.06), 但注意它的**纯多头版本
   这两个月是 0**, 拿满要靠空腿。
4. **市场中性形态的结论最扛打**: 产品 B 对冲版在旧窗 +34.1%、新窗 +4.6%, 两段都正, 回撤都在
   −11%/−2% 量级。**"现货多头篮子 + perp 空指数"这个工程形态本身比里面装哪个因子更重要。**
5. **截面动量继续恶化** (−0.38 → −2.62), 再次确认 crypto 横截面动量不可用。
